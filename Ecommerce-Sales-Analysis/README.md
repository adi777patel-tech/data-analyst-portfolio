# E-Commerce Sales Analysis

## Project Overview
An end-to-end data analytics project analyzing e-commerce sales, customer behavior, product performance, and profitability.

## Tools Used
- MySQL
- Microsoft Excel
- Power BI
- Power Query
- DAX

## Business Objectives
- Analyze total sales and profit.
- Identify top-performing products.
- Compare sales across cities and states.
- Understand customer purchasing patterns.
- Analyze product returns.
- Build an interactive business dashboard.

## Dataset
Synthetic practice dataset containing 50,000 orders, 5,000 customers, 250 products, and return records.

## Project Status
In Progress.
